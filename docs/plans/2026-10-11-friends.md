# Friends, and the cards they need — Implementation Plan (phase 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A friends list (friend codes + people you've played), each player's near-complete collections shared with their friends, a dot on spares a friend needs that opens the ordinary sell form, a pack-reveal chip, and the friend's Home line and market tag for such a listing.

**Architecture:** One pure shared module (`src/game/friends.js`) holds every rule: what a need is, the friend-code alphabet, the dot's text, the sanitiser the server applies. Four server callables in `functions/index.js` keep friendships, requests and codes (server-only collections); a fifth read, `myFriends`, returns the whole picture including friends' needs, so no database rule ever has to look up a friendship. Each player's own app publishes their needs to `profiles/{uid}` (owner-write, owner-read). A React provider loads `myFriends` once per sign-in and hands a card → friends-who-want-it map to My Collection, the pack reveal, the market and Home.

**Tech Stack:** React 18 + Vite, Firebase (Firestore, Cloud Functions v2 callables, Realtime Database for PvP rooms), Vitest (`npx vitest run <path>`), react-dom/server for render tests.

**Spec:** `docs/plans/2026-10-11-friends-design.md` (read it first).

**Refinement of the spec, already agreed in conversation (2026-10-11):** friends' needs and names are read through the `myFriends` callable rather than a Firestore rule that looks up `friends/{uid}` — same visibility (only friends), simpler to secure and to test. So `profiles/{uid}` is owner-read only, and the names live on the server-only `friends/{uid}` document. Played-with labels come from what is already shared: a league co-member's TEAM name and the league's name; a PvP opponent's name as the PvP room already shows it. // FRIENDS, AND THE CARDS THEY NEED (2026-10-11) — docs/plans/2026-10-11-friends-design.md.
//
// The user: "when a friend is within 2 cards of a collection and you pack a
// card, when you have My Collection filtered to 'Spare to sell or burn' have a
// little dot on any excess card that says 'A friend needs this card for a
// collection. List it?'" Every rule of it lives here, shared by the browser
// and the server (functions/prepare.mjs copies this file), so the two cannot
// disagree about what a need is or what a code looks like.
import { GOALS, GOALS_BY_ID, goalProgress, collectedKeys } from './collections.js';
import { canonicalKey, getCardByKey } from './cardSets.js';
import { getTeam } from '../cards/teams.js';

export const FRIENDS_MAX = 30;         // the most one Firestore `in` query takes
export const NEED_WITHIN = 2;          // "within 2 cards of a collection"
export const NEEDS_MAX = 60;
export const CODE_LENGTH = 6;
export const CODE_ALPHABET = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';   // no 0/O/1/I
const LABEL_MAX = 60;

export function makeFriendCode(rng = Math.random) {
  let s = '';
  for (let i = 0; i < CODE_LENGTH; i += 1) s += CODE_ALPHABET[Math.floor(rng() * CODE_ALPHABET.length) % CODE_ALPHABET.length];
  return s;
}

/** What a person typed, as a code — or null if it cannot be one. */
export function normalizeCode(input) {
  const s = String(input ?? '').toUpperCase().replace(/[^A-Z0-9]/g, '');
  if (s.length !== CODE_LENGTH || [...s].some(ch => !CODE_ALPHABET.includes(ch))) return null;
  return s;
}

/** A collection as a person says it: "Atlanta Hawks collection", "Super Season set". */
export function goalName(goal) {
  if (goal?.kind === 'team') {
    const t = getTeam(goal.label, { league: goal.league });
    return `${t ? `${t.city} ${t.name}` : goal.label} collection`;
  }
  if (goal?.kind === 'set') return String(goal.label ?? '').replace(/^Complete\s+/, '').replace(/\s+Set$/, ' set');
  return `${goal?.label ?? 'a'} collection`;
}

/** Card keys the owner holds ANY copy of (canonical). */
function heldKeys(collection) {
  return new Set(Object.entries(collection ?? {}).filter(([, e]) => (e?.count ?? 0) > 0).map(([k]) => canonicalKey(k)));
}

const byNeed = (a, b) => a.cardKey.localeCompare(b.cardKey) || a.goalId.localeCompare(b.goalId);

/**
 * WHAT THIS PLAYER NEEDS: every missing card of a collection not yet claimed
 * that is 1 to NEED_WITHIN cards short — and only cards they hold NO copy of,
 * since a spare waiting to be collected needs no friend.
 */
export function needsFromCollection(collection, claimedIds = new Set()) {
  const owned = collectedKeys(collection);
  const held = heldKeys(collection);
  const out = [];
  for (const g of GOALS) {
    if (claimedIds.has(g.id)) continue;
    const p = goalProgress(g.id, owned);
    if (!p || p.missingCount < 1 || p.missingCount > NEED_WITHIN) continue;
    for (const key of p.missing) {
      if (held.has(key)) continue;
      out.push({ cardKey: key, goalId: g.id, goalLabel: goalName(g), missing: p.missingCount });
    }
  }
  return out.sort(byNeed).slice(0, NEEDS_MAX);
}

const needId = n => `${n.cardKey}|${n.goalId}|${n.missing}`;
export function sameNeeds(a, b) {
  const x = (a ?? []).map(needId).sort();
  const y = (b ?? []).map(needId).sort();
  return x.length === y.length && x.every((v, i) => v === y[i]);
}

/** THE SERVER'S SANITISER: a friend's profile is written by their own app, so trust nothing in it. */
export function cleanNeeds(raw) {
  if (!Array.isArray(raw)) return [];
  const out = [];
  for (const n of raw) {
    if (out.length >= NEEDS_MAX) break;
    if (!n || typeof n !== 'object') continue;
    const { cardKey, goalId, goalLabel, missing } = n;
    if (typeof cardKey !== 'string' || !getCardByKey(cardKey)) continue;
    if (typeof goalId !== 'string' || !GOALS_BY_ID[goalId]) continue;
    if (!Number.isInteger(missing) || missing < 1 || missing > NEED_WITHIN) continue;
    out.push({ cardKey, goalId, goalLabel: String(goalLabel ?? '').slice(0, LABEL_MAX), missing });
  }
  return out;
}

/** Card (canonical key) → the friends who need it, one entry each at their nearest collection. */
export function wantsByCard(friends) {
  const out = new Map();
  for (const f of friends ?? []) {
    const best = new Map();
    for (const n of f?.needs ?? []) {
      const key = canonicalKey(n.cardKey);
      const cur = best.get(key);
      if (!cur || n.missing < cur.missing) best.set(key, { uid: f.uid, name: f.name, goalLabel: n.goalLabel, missing: n.missing });
    }
    for (const [key, w] of best) {
      if (!out.has(key)) out.set(key, []);
      out.get(key).push(w);
    }
  }
  return out;
}

export function listJoin(names) {
  const n = (names ?? []).filter(Boolean);
  if (n.length <= 1) return n[0] ?? '';
  return `${n.slice(0, -1).join(', ')} and ${n.at(-1)}`;
}

/** The dot's sentence. */
export function wantText(wants) {
  if (!wants?.length) return '';
  if (wants.length === 1) {
    const w = wants[0];
    return `${w.name} needs this for the ${w.goalLabel} (${w.missing} to go). List it?`;
  }
  return `${listJoin(wants.map(w => w.name))} need this for a collection. List it?`;
}

/** The pack reveal's chip for a pulled card, or null. */
export function friendNoteFor(wants, key) {
  const w = wants?.get?.(canonicalKey(key));
  if (!w?.length) return null;
  return `${listJoin(w.map(x => x.name))} ${w.length === 1 ? 'needs' : 'need'} this one`;
}

export function chunk(list, n) {
  const out = [];
  for (let i = 0; i < (list ?? []).length; i += n) out.push(list.slice(i, i + n));
  return out;
}

/**
 * FRIENDS (2026-10-11) — docs/plans/2026-10-11-friends-design.md.
 *
 * Friendships, requests and codes are written here and nowhere else; the
 * rules' closing match keeps all three from the client. A friend's needs are
 * read HERE too (myFriends), from the profile their own app keeps, so no rule
 * ever has to look a friendship up. Names: a requester's goes to the person
 * asked; a friend's is stored on each side when the friendship forms. The
 * name behind a code is never told to the person who typed it.
 */
const friendsRef = uid => db.doc(`friends/${uid}`);
const friendCodeRef = code => db.doc(`friendCodes/${code}`);
const friendRequestRef = (from, to) => db.doc(`friendRequests/${from}_${to}`);
const playedWithRef = (uid, other) => db.doc(`users/${uid}/playedWith/${other}`);
const safeUid = u => typeof u === 'string' && u.length > 0 && u.length <= 128 && !u.includes('/');
const nameOf = request => String(request.auth?.token?.name ?? '').trim().slice(0, 60) || 'A player';

async function ensureFriendCode(uid) {
  const mine = await friendsRef(uid).get();
  if (mine.exists && mine.data()?.code) return mine.data().code;
  for (let attempt = 0; attempt < 8; attempt += 1) {
    const code = makeFriendCode();
    const made = await db.runTransaction(async tx => {
      const taken = await tx.get(friendCodeRef(code));
      if (taken.exists) return false;
      tx.set(friendCodeRef(code), { uid });
      tx.set(friendsRef(uid), { code }, { merge: true });
      return true;
    });
    if (made) return code;
  }
  throw new HttpsError('unavailable', 'Could not make a friend code. Try again.');
}

/** Both sides of a friendship, in the transaction that read both documents. */
function befriend(tx, me, myName, myDoc, them, theirName, theirDoc) {
  tx.set(friendsRef(me), { ...(myDoc ?? {}), uids: [...new Set([...(myDoc?.uids ?? []), them])], names: { ...(myDoc?.names ?? {}), [them]: theirName } });
  tx.set(friendsRef(them), { ...(theirDoc ?? {}), uids: [...new Set([...(theirDoc?.uids ?? []), me])], names: { ...(theirDoc?.names ?? {}), [me]: myName } });
}

function capCheck(myDoc, theirDoc) {
  if ((myDoc?.uids ?? []).length >= FRIENDS_MAX) throw new HttpsError('resource-exhausted', `${FRIENDS_MAX} friends is the most you can have`);
  if ((theirDoc?.uids ?? []).length >= FRIENDS_MAX) throw new HttpsError('resource-exhausted', 'They already have the most friends they can have');
}

/** The whole picture: your code, friends (with their needs), requests and people you've played. */
export const myFriends = onCall({ region: 'us-central1' }, async request => {
  const uid = requireAuth(request);
  const code = await ensureFriendCode(uid);
  const mine = (await friendsRef(uid).get()).data() ?? {};
  const uids = (mine.uids ?? []).filter(safeUid);
  const friends = await Promise.all(uids.map(async f => {
    const p = (await db.doc(`profiles/${f}`).get()).data() ?? {};
    return { uid: f, name: mine.names?.[f] ?? 'A friend', needs: cleanNeeds(p.needs) };
  }));
  const [incoming, outgoing, played] = await Promise.all([
    db.collection('friendRequests').where('to', '==', uid).get(),
    db.collection('friendRequests').where('from', '==', uid).get(),
    db.collection(`users/${uid}/playedWith`).get(),
  ]);
  const known = new Set([...uids, uid]);
  return {
    code,
    friends: friends.sort((a, b) => a.name.localeCompare(b.name)),
    incoming: incoming.docs.map(d => ({ id: d.id, from: d.data().from, name: d.data().fromName ?? 'A player' })),
    outgoing: outgoing.docs.map(d => ({ id: d.id, to: d.data().to, label: d.data().toLabel ?? null })),
    playedWith: played.docs
      .map(d => ({ uid: d.id, label: d.data().label ?? 'A player', via: d.data().via ?? null }))
      .filter(p => !known.has(p.uid)),
  };
});

/** Ask by friend code, or one tap to someone you've played (`{ uid }`, only from your played-with list). */
export const requestFriend = onCall({ region: 'us-central1' }, async request => {
  const uid = requireAuth(request);
  const { code: rawCode, uid: rawUid } = request.data ?? {};
  let to;
  let toLabel;
  if (rawCode != null) {
    const code = normalizeCode(rawCode);
    if (!code) throw new HttpsError('invalid-argument', 'That is not a friend code');
    const c = await friendCodeRef(code).get();
    if (!c.exists) throw new HttpsError('not-found', 'No player has that code');
    to = c.data().uid;
    toLabel = `code ${code}`;
  } else if (safeUid(rawUid)) {
    const pw = await playedWithRef(uid, rawUid).get();
    if (!pw.exists) throw new HttpsError('permission-denied', 'Add them with their friend code');
    to = rawUid;
    toLabel = pw.data().label ?? null;
  } else {
    throw new HttpsError('invalid-argument', 'No friend given');
  }
  if (to === uid) throw new HttpsError('failed-precondition', 'That is your own code');
  return db.runTransaction(async tx => {
    const mineSnap = await tx.get(friendsRef(uid));
    const theirsSnap = await tx.get(friendsRef(to));
    const sent = await tx.get(friendRequestRef(uid, to));
    const back = await tx.get(friendRequestRef(to, uid));
    const myDoc = mineSnap.data() ?? {};
    const theirDoc = theirsSnap.data() ?? {};
    if ((myDoc.uids ?? []).includes(to)) throw new HttpsError('already-exists', 'You are already friends');
    capCheck(myDoc, theirDoc);
    if (sent.exists) throw new HttpsError('already-exists', 'Request already sent');
    // They asked you first: asking back is saying yes.
    if (back.exists) {
      befriend(tx, uid, nameOf(request), myDoc, to, back.data().fromName ?? 'A friend', theirDoc);
      tx.delete(friendRequestRef(to, uid));
      return { friends: true };
    }
    tx.set(friendRequestRef(uid, to), { from: uid, to, fromName: nameOf(request), toLabel, at: FieldValue.serverTimestamp() });
    return { sent: true };
  });
});

/** Yes or no to a request sent to you. */
export const answerFriendRequest = onCall({ region: 'us-central1' }, async request => {
  const uid = requireAuth(request);
  const id = String(request.data?.id ?? '');
  if (!id || id.includes('/')) throw new HttpsError('invalid-argument', 'No request given');
  return db.runTransaction(async tx => {
    const ref = db.doc(`friendRequests/${id}`);
    const snap = await tx.get(ref);
    if (!snap.exists) throw new HttpsError('not-found', 'That request is gone');
    const r = snap.data();
    if (r.to !== uid) throw new HttpsError('permission-denied', 'Not your request');
    if (!request.data?.accept) {
      tx.delete(ref);
      return { declined: true };
    }
    const myDoc = (await tx.get(friendsRef(uid))).data() ?? {};
    const theirDoc = (await tx.get(friendsRef(r.from))).data() ?? {};
    capCheck(myDoc, theirDoc);
    befriend(tx, uid, nameOf(request), myDoc, r.from, r.fromName ?? 'A friend', theirDoc);
    tx.delete(ref);
    return { friends: true, name: r.fromName ?? null };
  });
});

/** Unfriend: both sides, at once. Their needs stop reaching you with the next myFriends. */
export const removeFriend = onCall({ region: 'us-central1' }, async request => {
  const uid = requireAuth(request);
  const other = request.data?.uid;
  if (!safeUid(other)) throw new HttpsError('invalid-argument', 'No friend given');
  return db.runTransaction(async tx => {
    const myDoc = (await tx.get(friendsRef(uid))).data() ?? {};
    const theirDoc = (await tx.get(friendsRef(other))).data() ?? {};
    const strip = (doc, gone) => ({
      ...doc,
      uids: (doc.uids ?? []).filter(x => x !== gone),
      names: Object.fromEntries(Object.entries(doc.names ?? {}).filter(([k]) => k !== gone)),
    });
    tx.set(friendsRef(uid), strip(myDoc, other));
    tx.set(friendsRef(other), strip(theirDoc, uid));
    return { removed: true };
  });
});

// FRIENDS, loaded once per sign-in (2026-10-11). The overview comes from the
// myFriends callable — friends, their needs, requests, people you've played —
// and `wants` maps each card a friend needs to who needs it (wantsByCard).
// A failure leaves everything empty: My Collection, the reveal, the market and
// Home all read this, and none of them may break because Friends is down.
import { createContext, useCallback, useContext, useEffect, useMemo, useRef, useState } from 'react';
import { useAuth } from './AuthProvider.jsx';
import { myFriends, publishNeeds, loadPublishedNeeds } from './friends.js';
import { loadClaims } from './collection.js';
import { needsFromCollection, sameNeeds, wantsByCard } from '../game/friends.js';

const EMPTY = { overview: null, wants: new Map(), friendNames: new Map(), refresh: () => {}, error: null };
const Ctx = createContext(EMPTY);
export const useFriends = () => useContext(Ctx);

const REFRESH_EVERY_MS = 60_000;

export function FriendsProvider({ children }) {
  const { user } = useAuth();
  const [overview, setOverview] = useState(null);
  const [error, setError] = useState(null);
  const lastAt = useRef(0);
  const refresh = useCallback(async () => {
    if (!user) { setOverview(null); return; }
    lastAt.current = Date.now();
    try {
      setOverview(await myFriends());
      setError(null);
    } catch (e) {
      setError(e?.message ?? String(e));
    }
  }, [user]);
  useEffect(() => { refresh(); }, [refresh]);
  // Back to the tab after a while: a friend may have collected or listed.
  useEffect(() => {
    const onFocus = () => { if (Date.now() - lastAt.current > REFRESH_EVERY_MS) refresh(); };
    window.addEventListener('focus', onFocus);
    return () => window.removeEventListener('focus', onFocus);
  }, [refresh]);
  const value = useMemo(() => ({
    overview,
    wants: wantsByCard(overview?.friends ?? []),
    friendNames: new Map((overview?.friends ?? []).map(f => [f.uid, f.name])),
    refresh,
    error,
  }), [overview, refresh, error]);
  return <Ctx.Provider value={value}>{children}</Ctx.Provider>;
}

/**
 * PUBLISH YOUR NEEDS whenever your collection changes (after a pack, a buy, a
 * collect, a claim, and on load), and only when they changed — the first
 * comparison is with what the profile already holds.
 */
export function usePublishNeeds(user, collection) {
  const last = useRef(undefined);
  useEffect(() => {
    if (!user || !collection) return undefined;
    let live = true;
    const t = setTimeout(async () => {
      try {
        const claims = await loadClaims(user.uid);
        const next = needsFromCollection(collection, new Set(Object.keys(claims ?? {})));
        if (last.current === undefined) last.current = await loadPublishedNeeds(user.uid);
        if (!live || (last.current && sameNeeds(last.current, next))) return;
        await publishNeeds(user.uid, next);
        last.current = next;
      } catch (e) {
        console.warn('needs not published', e?.message ?? e);
      }
    }, 1500);
    return () => { live = false; clearTimeout(t); };
  }, [user, collection]);
}

```js
/** Listings by your friends of cards you need: `{ listing, friendName, goalLabel }`, cheapest first. */
export function friendListingsYouNeed(listings, friendNames, myNeeds) {
  const need = new Map();
  for (const n of myNeeds ?? []) if (!need.has(canonicalKey(n.cardKey))) need.set(canonicalKey(n.cardKey), n);
  return (listings ?? [])
    .filter(l => friendNames?.has(l.seller) && need.has(canonicalKey(l.cardKey)) && getCardByKey(l.cardKey))
    .map(l => ({ listing: l, friendName: friendNames.get(l.seller), goalLabel: need.get(canonicalKey(l.cardKey)).goalLabel }))
    .sort((a, b) => a.listing.price - b.listing.price);
}
```

/** Open listings by these sellers — your friends — in Firestore's 30-a-query `in` chunks. */
export async function loadListingsBy(sellerUids) {
  const out = [];

    const snap = await getDocs(query(listingsRef(), where('seller', 'in', part)));
